# SharkyApp 🦈

Welcome to **SharkyApp**.

This is an Android application designed to provide an optimized browsing experience for the [Sharkipedia](https://www.sharkipedia.org/) website, dedicated to shark conservation and education.

## Installation Guide ⚙️

1. Download the APK file from the link below.
2. Copy the file to your Android device.
3. Open the APK file and follow the instructions to install the app.
4. If this is your first time installing an app outside Google Play, enable the "Allow installation of apps from unknown sources" option.

---

## Detailed Features

- **Integrated WebView navigation:** Access Sharkipedia directly from the app.
- **Modern design:** Interface based on Material Design 3 and Jetpack Compose.
- **Full JavaScript support:** For a smooth web experience.
- **Compatibility:** Android Studio Flamingo (2024.3.1 Patch 1) or higher, Gradle 8.0+, Pixel 8 Pro device or emulator (API 35)+.
