# SharkyApp 🦈

Bienvenido a **SharkyApp**.

Esta es una aplicación Android diseñada para ofrecer una experiencia optimizada de navegación para el sitio [Sharkipedia](https://www.sharkipedia.org/), dedicada a la conservación y educación sobre tiburones.

## Características principales

- Navegación integrada con WebView.
- Diseño moderno con Material Design 3 y Jetpack Compose.
- Soporte completo de JavaScript.
- Requisitos: Android Studio Flamingo (2024.3.1 Patch 1) o superior, Gradle 8.0+, dispositivo o emulador Pixel 8 Pro (API 35)+.
